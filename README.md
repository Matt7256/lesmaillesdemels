# Les Mailles de Mels

Create a beautiful, modern and elegant French website for a small handmade crochet clothing business.

The business creates handmade crochet clothing and accessories, mainly for girls and women, but also for boys and men depending on the project. Every creation is handmade and unique.

The website should feel warm, creative, feminine but not overly childish, premium but still accessible. The goal is to showcase the creator's work and encourage visitors to contact her to order a custom creation.

General design direction

Use a clean, modern and visually attractive design with a strong focus on photography.

Style:

Elegant

Warm

Handmade / artisanal

Soft and creative

Modern rather than old-fashioned

Feminine without being excessively pink

Premium but approachable

Use a soft and refined color palette inspired by handmade crochet and natural materials:

warm cream / off-white background

soft beige

subtle brown / caramel accents

a muted dusty pink or terracotta accent

dark brown or charcoal for text

Use beautiful typography with:

an elegant serif font for major headings

a clean modern sans-serif font for body text

Use generous whitespace, rounded corners where appropriate, subtle shadows and very light animations.

The website must be fully responsive and look excellent on mobile, since many visitors will probably come from Instagram.

Do not make the website look like a generic ecommerce template. It should feel like a small independent handmade brand.

Website structure

Create these 4 main pages:

Accueil

À propos

Tarifs

Inspirations

Also include a clear contact/order call-to-action throughout the website.

The primary ways to contact/order should be:

WhatsApp

Instagram

IMPORTANT UX REQUIREMENTS

The website should make it extremely obvious how someone can order.

A visitor should never have to search for the contact method.

Include WhatsApp / Instagram CTAs naturally throughout the website.

The website is NOT a traditional ecommerce store.

There should be no shopping cart, online payment or checkout system.

The customer should contact the creator to discuss the desired creation, size, colors, customization and price.

Make the site feel trustworthy and professional.

Use realistic placeholder content, but clearly structure it so the owner can easily replace:

images

prices

brand name

Instagram link

WhatsApp link

descriptions

TECHNICAL / QUALITY REQUIREMENTS

Fully responsive

Mobile-first design

Excellent mobile navigation

Fast-loading images

Accessible contrast

Smooth but subtle animations

No excessive animations

No unnecessary features

No fake reviews

No fake customer numbers

No invented business claims

No lorem ipsum

Use French language throughout the visible website

Keep the code clean and reusable

Use reusable components for buttons, cards, navigation and gallery items

Make the website easy to maintain and modify later

Before finishing, verify every page on both desktop and mobile layouts and fix any visual inconsistencies.

The final result should look like a real small premium handmade crochet brand website that could be shown to a potential customer immediately.
